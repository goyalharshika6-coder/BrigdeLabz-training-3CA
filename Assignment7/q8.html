CSS Box Model Exploration

Every HTML element consists of content, padding, border and margin.

Content

Actual content of the element.

Box Model Parts

Content: Actual text or information.

Padding: Space between content and border.

Border: Line around the padding and content.

Margin: Space outside the border.

Outline: Extra line outside the element.

CSS Cheat Sheet

Learn the basics of CSS

Flexbox

Used to arrange items in a row or column.

display: flex;

CSS Grid

Used to create rows and columns.

display: grid;

Media Query

Used to make layouts responsive.

@media (max-width: 600px)

Box Sizing

Includes padding and border in element width.

box-sizing: border-box;

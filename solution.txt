JavaScript Interview-Level Questions:-
1. What is the difference between == and ===?
- == compares values after type conversion if needed.
- === compares both value and data type.
Example:
console.log(5 == "5");  // true
console.log(5 === "5"); // false


2. What is the difference between undefined and null?
- undefined means a variable has been declared but has not been assigned a value.
- null means we intentionally assign an empty value.
Example:
let a;
let b = null;

console.log(a); // undefined
console.log(b); // null


3. What is the difference between for...in and for...of?
- for...in is used to access the keys or property names of an object.
- for...of is used to access the values of an iterable, such as an array or string.
Example:
let arr = [10, 20, 30];

for (let i in arr) {
    console.log(i); // 0, 1, 2
}

for (let value of arr) {
    console.log(value); // 10, 20, 30
}


4. Can a function return another function? Give a real-world use case.
Yes, a function can return another function. This is useful when we want to create functions with specific settings or behavior.

Example:
function greet() {
    return function() {
        console.log("Hello!");
    };
}

let result = greet();
result(); // Hello!


Real-world use case: Creating a login function with specific permissions for different users.
5. What happens if a function has no explicit return statement?
If a function does not have a return statement, it returns undefined by default.

Example:
function add() {
    let a = 5 + 5;
}

console.log(add()); // undefined


6. What is the difference between passing a primitive value and passing an object to a function?
- Primitive value: The function receives a copy of the value. Changing it inside the function does not change the original variable.
- Object: The function receives a copy of the object reference. Changing an object's properties can affect the original object.
Example:
function change(x) {
    x = 20;
}

let a = 10;
change(a);
console.log(a); // 10


For an object:
function change(obj) {
    obj.name = "Rahul";
}

let user = { name: "Aman" };
change(user);
console.log(user.name); // Rahul


7. What is the difference between shallow copying and deep copying an object?
- Shallow copy: Copies the top-level properties, but nested objects are still shared.
- Deep copy: Copies nested objects too, so changes to nested data do not affect the original.
Example:
let original = {
    name: "Aman",
    address: { city: "Mathura" }
};

let copy = { ...original }; // Shallow copy
copy.address.city = "Delhi";

console.log(original.address.city); // Delhi


A deep copy can be created using structuredClone() for supported data types.
8. Why is NaN !== NaN true?
NaN means “Not a Number.” In JavaScript, NaN is not equal to any value, including itself.

Example:
console.log(NaN === NaN);  // false
console.log(NaN !== NaN);  // true
We can check for NaN using Number.isNaN().

9. What is the difference between function declarations and function expressions regarding hoisting?
- Function declaration: Can generally be called before it appears in the code because the function is hoisted with its definition.
- Function expression: If assigned to a let or const variable, it cannot be called before initialization.
Example:
// Function declaration
hello();

function hello() {
    console.log("Hello");
}


Output: Hello

Function expression:
sayHi(); // ReferenceError

const sayHi = function() {
    console.log("Hi");
};


10. When would you use an arrow function instead of a regular function?
- Use an arrow function for short callbacks and when you want to keep this from the surrounding scope.
- Use a regular function for object methods that need their own this, or when you need a constructor.
Example:
let numbers = [1, 2, 3];

let result = numbers.map(n => n * 2);

console.log(result); // [2, 4, 6]

Output: [2, 4, 6]

An arrow function makes the callback shorter and easier to read.
